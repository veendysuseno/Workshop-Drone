# Workshop Unmanned Aerial Vehicle (UAV) – Drone DJI Tello

Modul workshop yang membahas dasar-dasar **Unmanned Aerial Vehicle (UAV)** atau drone, mulai dari pengenalan teknologi, komponen dan prinsip kerja drone, hingga praktik pengendalian **DJI Tello** menggunakan aplikasi Tello App, DroneBlocks, dan bahasa pemrograman Python.

## 🎯 Capaian Pembelajaran

Setelah mengikuti workshop ini, peserta diharapkan mampu:

1. Memahami kegunaan, jenis-jenis, kelebihan dan kekurangan, komponen utama, serta prinsip kerja **Unmanned Aerial Vehicle (UAV)**.
2. Memahami pengendalian **DJI Tello** menggunakan aplikasi **Tello App**.
3. Memahami pengendalian **DJI Tello** menggunakan aplikasi **DroneBlocks**.
4. Memahami pengendalian **DJI Tello** menggunakan bahasa pemrograman **Python**.

## 📚 Indeks Workshop

### BAB I – Pengenalan Unmanned Aerial Vehicle (UAV)

- **1.1** Pengertian Unmanned Aerial Vehicle (UAV) / Drone
- **1.2** Kegunaan Unmanned Aerial Vehicle (UAV) / Drone
- **1.3** Jenis-Jenis Unmanned Aerial Vehicle (UAV) / Drone
- **1.4** Kelebihan & Kekurangan Unmanned Aerial Vehicle (UAV) / Drone
- **1.5** Komponen Utama Unmanned Aerial Vehicle (UAV) / Drone
- **1.6** Prinsip Kerja Unmanned Aerial Vehicle (UAV) / Drone

### BAB II – Pengenalan Kendali DJI Tello dengan Tello App

- **2.1** Spesifikasi DJI Tello
- **2.2** Pengenalan Tello App
- **2.3** Kendali DJI Tello melalui Tello App

### BAB III – Pengenalan Kendali DJI Tello dengan DroneBlocks

- **3.1** Pengenalan Aplikasi DroneBlocks
- **3.2** Pengenalan Blok Program DroneBlocks
- **3.3** Kendali DJI Tello melalui Aplikasi DroneBlocks

### BAB IV – Pengenalan Kendali DJI Tello dengan Python

- **4.1** Pengenalan Bahasa Pemrograman Python
- **4.2** Pengenalan Syntax Program Python
- **4.3** Kendali DJI Tello melalui Bahasa Pemrograman Python
